# صفحات کو نیچے سے برابر کرنے کا ٹول

Word سے بنی PDF میں بعض صفحات کی آخری لائن نیچے کے مارجن تک نہیں پہنچتی۔ وجہ یہ ہوتی ہے کہ کوئی عنوان، بولڈ یا بڑا لفظ تھوڑی سی زیادہ جگہ لے لیتا ہے، اور Word اگلی لائن کو پوری جگہ نہ ملنے پر اگلے صفحے پر دھکیل دیتا ہے۔ یہ ٹول ایسے ہر صفحے کو اس کی اپنی جگہ پر برابر کر دیتا ہے:

- **پہلی لائن** اپنی جگہ پر رہتی ہے۔
- **آخری لائن** ٹھیک وہاں آ جاتی ہے جہاں Word کے بھرے ہوئے صفحات کی آخری لائن ہوتی ہے۔
- **درمیانی لائنوں** میں بچی ہوئی جگہ برابر بانٹ دی جاتی ہے۔

کوئی لائن ایک صفحے سے دوسرے صفحے پر نہیں جاتی، اور دائیں بائیں کی justification ویسی ہی رہتی ہے۔

## یہ کیسے کام کرتا ہے

1. PDF کے اندر ہر حرف کی جگہ پڑھی جاتی ہے۔
2. جن حروف کی baseline ایک ہو، وہ ایک لائن کا گروپ بن جاتے ہیں۔ نستعلیق کے ترچھے پن کے باوجود اکثر حروف اصل baseline پر بیٹھتے ہیں، اسی سے لائن پہچانی جاتی ہے۔
3. ہر گروپ کو PDF کے اندر ہی تھوڑا نیچے کھسکا دیا جاتا ہے۔

لائنوں کو کاٹا نہیں جاتا، اس لیے نستعلیق کے دامن، فونٹ، vector معیار اور selectable متن سب جوں کے توں رہتے ہیں۔ خط کشیدہ (underline) بھی اپنی لائن کے ساتھ چلتا ہے۔ صفحہ نمبر اور footer نیچے کے مارجن سے باہر ہوتے ہیں، اس لیے انہیں نہیں چھیڑا جاتا۔

## تنصیب (ایک بار)

1. [Python](https://www.python.org/downloads/) انسٹال کریں (انسٹال کرتے وقت "Add Python to PATH" پر نشان لگائیں)۔
2. Command Prompt میں یہ کمانڈ چلائیں:
   ```
   pip install pikepdf
   ```

## استعمال

### آسان طریقہ (Windows)
PDF فائل کو `run_windows.bat` پر drag کر کے چھوڑ دیں۔ وہ نیچے کا مارجن اور صفحات کی رینج پوچھے گا۔ نتیجہ اسی فولڈر میں `نام_barabar.pdf` کے نام سے بن جائے گا۔

### کمانڈ کے ذریعے
```
python bottom_align.py کتاب.pdf کتاب_برابر.pdf --bottom-margin 0.5in --pages 5-120 --skip 23,47,90
```

| اختیار | مطلب |
|---|---|
| `--bottom-margin` | Word میں سیٹ کیا ہوا نیچے کا مارجن (لازمی)۔ مثال: `0.5in`، `1.27cm`، `12.7mm`، `36pt`۔ اکائی نہ لکھیں تو انچ مانا جائے گا |
| `--top-margin` | (اختیاری) اوپر کا مارجن۔ اگر صفحے پر ہیڈر ہو تو دیں، تاکہ ہیڈر کو متن کی لائن نہ سمجھا جائے |
| `--pages` | کن صفحات پر کام ہو، مثلاً `5-120`۔ نہ دیں تو تمام صفحات |
| `--skip` | کون سے صفحات نہ چھیڑے جائیں، جیسے ابواب کے آخری صفحات: `23,47,90-91` |
| `--max-lines` | اگر کسی صفحے پر کمی اتنی لائنوں سے زیادہ ہو تو اسے چھوڑ دیا جائے (پہلے سے `2`)۔ یہ ابواب کے آخری صفحات کے لیے حفاظتی قاعدہ ہے |
| `--mode` | `equal`: ہر دو لائنوں کے درمیان برابر اضافہ (پہلے سے)۔ `proportional`: موجودہ فاصلوں کے تناسب سے |
| `--target` | (اختیاری) آخری لائن کی baseline صفحے کے نچلے کنارے سے کتنی اوپر ہو۔ نہ دیں تو ٹول اس صفحے سے خود معلوم کرے گا جس کی آخری لائن سب سے نیچے ہے |

ٹول ہر صفحے کی رپورٹ دکھاتا ہے: کتنی کمی تھی، صفحہ برابر کیا گیا یا چھوڑ دیا گیا۔ اصل فائل کو کبھی نہیں چھیڑا جاتا۔

## حدود (فی الحال)

- صرف Word یا اسی طرح کے پروگرام سے بنی PDF کے لیے ہے۔ scan شدہ PDF پر کام نہیں کرتا۔
- حواشی (footnotes) والے صفحات پر ابھی جانچ باقی ہے۔
- PDF کے اندرونی links (مثلاً فہرست کے) اپنی پرانی جگہ پر رہتے ہیں۔

## نمونہ

`examples/before.pdf` ایک تجرباتی فائل ہے جس میں 21 لائنوں والے صفحات اور درمیان میں عنوانات ہیں۔ `examples/after.pdf` اسی فائل پر ٹول چلانے کا نتیجہ ہے:

```
python bottom_align.py examples/before.pdf examples/after.pdf --bottom-margin 34.3pt --max-lines 5
```
